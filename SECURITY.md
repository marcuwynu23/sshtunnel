# Security Policy

## Supported Versions

Security updates are provided for the latest code on the `main` branch and the most recent release.

| Version | Supported |
| ------- | --------- |
| Latest release | :white_check_mark: |
| `main` branch | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately by email:

- **Email:** `help@marcuwynu.space`
- **Subject:** `[sshtunnel] Security report`

Include as much detail as possible:

- A clear description of the vulnerability
- Steps to reproduce or proof-of-concept
- Impact assessment (what an attacker can do)
- Affected versions/commit hashes
- Any suggested remediation

## What to Expect

- Initial acknowledgment within **5 business days**
- Triage and impact assessment after acknowledgment
- Fix timeline depends on severity and complexity
- Coordinated disclosure after a fix is available

Thank you for helping keep `sshtunnel` and its users safe.
